# 膝痛専門整体院 Liberate ｜ 口コミ収集ツール

患者さんが選択肢をタップ →（ブラウザ内で）自然な口コミ文を自動生成 → コピーしてGoogle／ホットペッパーに投稿、という流れのツールです。

- ファイル：`index.html`（これ1枚で完結。サーバー・API・費用は不要）
- 仕組み：「単一HTML」方式。GitHub Pages にそのまま置けます。
- AIの代わりに、選んだ項目＋一言から「型」をランダムに選んで文章を組み立てます（毎回文面が変わる／院長のNGワードは出ない設計）。
- デザイン：白基調×ティール（清潔・読みやすさ重視の太めゴシック）。各設問に「複数回答OK」バッジを表示。

---

## 投稿先URL（2か所・設定済み）

`index.html` 上部に設定済みです。変更したいときはここを書き替えてください。

```js
const GOOGLE_REVIEW_URL    = "https://g.page/r/Cc8KV9iWUiniEAI/review";          // Google（設定済み）
const HOTPEPPER_REVIEW_URL = "https://beauty.hotpepper.jp/kr/slnH000718879/review/"; // ホットペッパー リバレイト(設定済み)
```

> ホットペッパーの口コミ投稿は、HPB側の仕様で**ログインや予約履歴が必要な場合があります**（Googleは誰でもすぐ投稿可）。リンクは自院のクチコミページに飛びます。

### ① Google投稿URLの取り方
1. Googleで「膝痛専門整体院 Liberate」を検索
2. 右側（スマホは店舗ページ）の「クチコミ」→「**クチコミを書く**」
3. そのとき開いたページのURL（`https://g.page/r/.../review` などの形）をコピー
4. 上の `GOOGLE_REVIEW_URL = "..."` の中に貼り付けて保存

### ② ホットペッパービューティー投稿URLの取り方
1. ホットペッパービューティーの自院ページを開く
2. 「クチコミ」タブ →「**クチコミを投稿する**」のページURLをコピー
3. 上の `HOTPEPPER_REVIEW_URL = "..."` の中に貼り付けて保存
4. 投稿ページのURLが分からなければ、自院ページのURLでもOKです

> どちらも分からなければ、URL（または自院ページのURL）をチャットに貼ってもらえれば組み込みます。
> 片方だけ使う場合は、もう片方はそのままでも問題ありません（使わなければOK）。

## 使い方（患者さん）

1. QRコードやタブレットからこのページを開く
2. Q1〜Q5を **タップで選ぶ**（複数選べます）
3. Q6で **一言**（なくてもOK／🎤声で入力も可）
4. 「口コミ文を作成する」→ 文章ができる
5. 「文章をコピーする」→ **Googleかホットペッパーのボタンを押す** → 貼り付けて投稿（どちらか一方でも両方でもOK）

- 文章はその場で**自由に書き換え**できます（文字部分をタップして編集）。
- 「↻ 別の文章を作る」で違う言い回しに作り直せます。

---

## おすすめの運用

- **院内にタブレットを設置**し、施術後にその場で書いてもらうと完了率が大きく上がります（音声入力との相性◎）。
- QRコードはこのページ（GitHub PagesのURL）に向けて作成します。

---

## 公開（GitHub Pages）する場合

腸セルフチェックと同じ手順です。
1. このフォルダ（`index.html`）をGitHubのリポジトリに置く
2. Settings → Pages で公開
3. 発行されたURLでQRコードを作成

## 設計メモ（院長の方針を反映済み）

- 「完治」「治る」「改善する」などの断定・誇大表現は出ません（生成側で禁止）。
- 具体的な金額には触れません。
- 選ばれていない情報（院長の対応・院内の様子など）は、**選ばれたときだけ**文章に入ります（創作しない）。
- Q5の「原因を理解できた／自分でケアできる／あきらめていたけど希望が持てた」は、Liberateの差別化軸が患者さんの言葉で口コミに乗る最重要項目です。
